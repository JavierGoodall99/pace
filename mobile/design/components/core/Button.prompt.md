Pill-shaped mono-uppercase button, PACE's primary CTA control — use for any call to action.

```jsx
<Button variant="primary">Get Early Access</Button>
<Button variant="secondary" size="sm">Log In</Button>
<Button variant="ghost" disabled>Continue</Button>
```

Variants: `primary` (ember→flare on hover, ink text), `secondary` (bone→ember inverse), `ghost` (outline, for tertiary actions like "skip"). Sizes: `md` (default, 56px-ish tall), `sm` (compact, chip-adjacent).
